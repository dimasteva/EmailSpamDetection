# Email Spam Detection

A machine learning and deep learning project for detecting spam emails. This repository combines classical models with advanced neural networks to provide accurate and interpretable predictions.  
**Developed at the Petnica Research Station (Istraživačka stanica Petnica).**

## Features

- **Data Preprocessing & Feature Engineering**  
  Optimized K-word selection, dataset balancing, and preparation for modeling.

- **Machine Learning Models**  
  Includes Random Forest, Decision Tree, Naive Bayes, and Logistic Regression.

- **Deep Learning**  
  Bi-LSTM model using GloVe embeddings, with hyperparameter tuning for optimal performance.

- **Model Evaluation & Interpretation**  
  10-fold cross-validation, statistical tests, and SHAP analysis for feature importance.

- **Continuous Improvement**  
  Iterative hyperparameter tuning, model testing, and dataset updates to improve accuracy.

## Technologies Used

- Python  
- TensorFlow / Keras  
- scikit-learn  
- GloVe embeddings  
- SHAP  
- Pandas & NumPy
